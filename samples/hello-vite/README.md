# Hello Vite + Kotlin

A sample web application demonstrating Kotlin/JS with Vite integration.

## Features

- 🚀 Kotlin/JS compiled to ES modules
- ⚡ Vite dev server with Hot Module Replacement
- 📦 Production bundling with Rollup
- 🔄 Auto-recompilation on Kotlin source changes

## Quick Start

### 1. Scaffold the Vite project

```bash
# From the kbuild root directory
./gradlew :samples:hello-vite:scaffold
```

Or programmatically:

```kotlin
val kmpProject = kmpProject("hello-vite", projectRoot) {
    js()
}

val webProject = kmpProject.webProject(
    title = "Hello Vite + Kotlin"
)

webProject.scaffold(initFunction = "App.main")
```

### 2. Install npm dependencies

```bash
cd samples/hello-vite/web
npm install
```

### 3. Start development server

```bash
# Compile Kotlin and start Vite
./gradlew :samples:hello-vite:dev
```

Or:

```bash
# Compile Kotlin first
./gradlew :samples:hello-vite:compileJs

# Then start Vite
cd web
npm run dev
```

### 4. Open in browser

Visit http://localhost:5173


## How It Works

1. **Kotlin Compilation**: Kotlin/JS compiles your code to ES modules in `build/js/`
2. **Vite Import**: `web/src/main.js` imports the Kotlin module via the `@kotlin` alias
3. **HMR**: Vite watches `build/js/` and triggers HMR when Kotlin output changes
4. **Production Build**: Rollup bundles everything for optimized output

## API

The sample exports these functions from Kotlin:

```kotlin
@JsExport
object App {
    fun main()                    // Initialize the app
    fun greet(name: String): String  // Returns a greeting
    fun reset()                   // Reset the counter
}
```

## Development Workflow

For the best experience:

1. Keep `npm run dev` running in one terminal
2. Edit Kotlin files in `src/jsMain/kotlin/`
3. Run `./gradlew compileJs` to recompile (or use `devWatch()` for auto-recompile)
4. See changes instantly in browser via HMR
